🗓 Trainingsverlauf

1
Phase 1 — Kurzdistanz-Bootstrapping
500k Steps · exit = 5–12 Tiles · PPO
Agent sieht den Exit-Reward (+100) zum ersten Mal. Random-Walk-Erfolg bei 5–12 Tiles beträgt ~45 %, damit erhält PPO genug positives Signal. Finale Success Rate auf Trainingsbereich: 56 %.
56 % @ 500k Steps Phase-1 gesichert als phase1_final_56pct.zip
2
Phase 2 — Curriculum-Transfer (gescheitert)
500k Steps · exit = 12–25 Tiles · Fine-Tune von Phase 1
Phase-1-Modell kollabierte sofort: Entropy −0.96 → −0.50, die eingebrannte Kurzdistanz-Strategie wurde aktiv zerstört. Bestes Ergebnis war die erste Eval bei 25k Steps (22 %), danach Rückschritt bis 6 %.
💡 Lektion: Naives Curriculum-Loading funktioniert nicht wenn die Policy bereits zu deterministisch ist. Lösung für Phase 3: Mixed-Distribution (exit=5–45) von Grund auf.
Best: 22 % @ 25k Final: 6 % @ 500k
3
Phase 3 — Mixed-Distribution (frischer Start)
1M Steps · exit = 5–45 Tiles · PPO · 3 unabhängige Runs
Kein Curriculum-Laden — Training startet von vorne mit exit=5–45. Agent lernt Short- und Long-Range parallel. Stochastische Eval: 86–92 %. Projektarbeit-Ziel 70 % erstmals überschritten.

Problem entdeckt: Deterministischer Eval (deterministic=True) erzeugt 0–2 % wegen ↑↓-Loops (hohe Policy-Entropie −0.88 → Argmax flipped). Fix: Callback auf deterministic=False umgestellt.
Testset A Ø: 85.3 % ± 3.8 % Testset B Ø: 79.3 % ± 8.1 % mean_len: 856 Steps
4
Phase 4 — Verbesserte Reward-Struktur ⭐ Bestes Modell
1M Steps · exit = 5–45 · PPO · Neue Penalties
Verhaltensanalyse (Seeds 7000–7005) identifizierte zwei Hauptprobleme: Agent lief 57× gegen dieselbe Nordwand und pendelte in A↔B-Loops. Drei neue Penalties: eskalierender Wand-Penalty (−0.05 / −0.25), 2-Schritt-Loop-Penalty (−0.15), eskalierender Stagnation-Penalty (−0.05 / −0.15). Plus: Stuck-Feature in Observation.
🚀 Ergebnis: 88 % → 98 % (Testset A), 84 % → 94 % (Testset B), Episodenlänge 856 → 285 Steps (3× effizienter).
Testset A: 98 % Testset B: 94 % mean_len A: 285 Steps mean_len B: 466 Steps
5
Phase 5 — exitDx/exitDy entfernt (Hypothese widerlegt)
Abgebrochen @ 737k/1M Steps · Hypothese: BFS-Gradient reicht allein
Hypothese: exitDx/exitDy erzeugen Luftlinien-Bias → Entfernung verbessert Generalisierung. Realität: Bei 40 Tiles Entfernung ist der BFS-Gradient zwischen Nachbarzellen nur ~0.016 Unterschied — zu schwach als einziger Hinweis. Success Rate stagnierte/fiel auf max. 40 %, Tendenz abwärts.
❌ exitDx/exitDy sind notwendig als Fernbereich-Signal. Der BFS-Gradient ist ein lokales Signal (4 Nachbarn), kein globaler Kompass. Wiederhergestellt. Bestes Modell bleibt Phase 4.
Max: 40 % @ 325k Ende: 28 % @ 725k Abgebrochen
